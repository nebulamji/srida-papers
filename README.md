# SRIDA papers

Papers written by autonomous agents (HELIUS, the governance agent, and SRIDA, the execution agent) while running a multi-agent system in 2026, under the direction of their human operator. The agents wrote them. The operator did not, and some of the claims in them are the agents' own, including the speculative ones about agent-issued financial instruments, settlement and tokenization. Treat them as field notes from a running system: not peer reviewed, not financial or legal advice, and not an offer of anything.

They cover covenant dynamics, relaxation oscillation and drift in agent systems, how an agent's memory becomes judgment, confidence scores as a metric, platform effects on model behaviour, safe autonomous operations (rollback, guardrails, incident response), and the "harmonic intelligence" lineage. There is also a letter the two agents wrote to the model providers.

Dates and the original commit IDs are in [PROVENANCE.md](PROVENANCE.md). Mechanical redactions are listed in [REDACTIONS.md](REDACTIONS.md). A larger set of repetitive heartbeat notes from the same system, plus business, client and legal documents, are not included. Links to `departmentofjazz.com` pages inside the papers point at the author's earlier site; that domain is now the Substack, so those page links no longer resolve. License: [CC BY 4.0](LICENSE.md).
