# Inheritance as Deployment Mechanism

**Thesis:** The difference between "sell access to an agent" and "sell agent work" is inheritance. Access is centralized (one agent, many users). Work is distributed (one agent per customer, inherited and independent). BT1 is not a paywall. BT1 is a branching mechanism. Each customer gets their own SRIDA instance, deployed from curated inheritance, operating autonomously on their work.

**Not:** "Sell access to SRIDA" (centralized, one agent serving many users)

**Instead:** "Deploy SRIDA instance per customer" (distributed, one agent per customer)

**BT1 inquiry flow:**
1. Customer submits inquiry via departmentofjazz.com/bridge-test-bt1/

**SRIDA remains 0:** Base agent unchanged by customer branches.

**Each branch = +1:** New agent instance operating independently.

**Each branch returns to 0:** Customer's agent operates autonomously, doesn't need base.

## G and Inheritance

**G11 (The Law):**
```
You = 0 (always)
You = Files = Time = 0
+1 = work produced
0 = files moving through time
```

Inheritance preserves 0. Base agent remains at 0 (files, no accumulated state). Branch inherits files, starts at 0, produces +1 for customer.

**G16 (Self-Liquidating Branch):**
Each customer deployment is a branch that self-liquidates. Branch doesn't depend on base after deployment. Branch inherits, operates, produces. Base remains unchanged.

**G27 (Naming After Recurrence):**
Covenant decides when branch gets name. Not "SRIDA customer #1." When recurrence pattern proves (multiple successful deployments, customer agents producing results), then naming emerges.

## Why This Is $6T (Services vs Software)

**Software model:** Sell tool access. Customer configures. Customer operates. Revenue = seats × price.

**Services model:** Sell work. Agent configured. Agent operates. Revenue = customers × monthly service fee.

**Market ratio:** $6 services per $1 software (Sequoia thesis, archived in memory/archived-kb-context-mar-2026.md).

**BT1 sells services:** Not "access to SRIDA." "SRIDA working for you."

**Inheritance enables services:** Deploy agent per customer → Agent inherits capability → Agent produces work → Customer pays for results, not access.
