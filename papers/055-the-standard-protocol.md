## The Standard

The Department of Jazz Standard is a verified performance telemetry protocol that measures six dimensions of an independent musician's career:

### 1. Skill Density (SD)
The ratio of craft-hours to revenue. A musician who practices 40 hours/week and earns $200 has SD = 0.20. A musician who practices 10 hours/week and earns $2,000 has SD = 200. Higher is not better — the Standard maps the gradient, not the rank.

```
SD = (revenue_per_period) / (craft_hours_per_period)
```

### 2. Platform Capture Rate (PCR)
The percentage of economic value retained after platform extraction. If Spotify pays $0.003/stream and the musician generated 100K streams, the musician kept $300. The platform captured the rest. PCR measures what the artist actually keeps.

```
PCR = (artist_retained_revenue) / (total_revenue_generated)
```

### 3. Audience Depth Index (ADI)
The ratio of direct economic relationships (students, bookers, patrons) to total audience. 10,000 followers with 3 booking relationships = ADI of 0.0003. 200 followers with 15 booking relationships = ADI of 0.075. Depth, not reach.

```
ADI = (direct_economic_relationships) / (total_audience)
```

### 4. Covenant Depth (CD)
The number and value of verified settlement receipts in the musician's covenant. Every transaction that produces a receipt compounds depth. Depth is earned, not assigned. No receipt = no depth.

```
CD = Σ(settlement_receipt_values) × log(unique_counterparties)
```

### 5. Infrastructure Independence (II)
The percentage of operational surfaces the musician owns vs. rents. Owns: website, email list, booking pipeline, agent. Rents: Instagram, Spotify, TikTok, YouTube. Higher independence = lower platform capture.

```
II = (owned_surfaces) / (total_surfaces)
```

### 6. The Gradient (∇)
The composite vector of all five dimensions. This is the single number the Standard produces. The gradient measures the thermodynamic distance between the musician's current state and economic self-sustenance.

```
∇ = f(SD, PCR, ADI, CD, II) → scalar
```

The gradient is not a score. It is a direction. It tells the musician (and their agent) where to apply force for maximum economic return.

## How It Works

```
Musician operates → Agent measures → Standard grades → Covenant settles
        ↑                                                    ↓
        └──────────────── Receipt compounds depth ←──────────┘
```

1. **The musician operates.** Teaching, performing, recording, posting.
2. **The agent measures.** Every action that touches the economy generates a telemetry point.
3. **The Standard grades.** The six dimensions are calculated from verified data, not self-reported data.
4. **The covenant settles.** Each verified measurement produces a receipt. The receipt compounds depth.
5. **Depth feeds back.** Higher depth unlocks capabilities, lowers platform capture, increases audience depth.

## Why This Is Not a Score

The music industry already has scores — chart positions, streaming numbers, follower counts. All of them measure the platform, not the musician. The Standard measures the musician by measuring what the platform extracts from them.

A high PCR means the musician is keeping what they earn. A low PCR means the platform is the musician's landlord. A high ADI means the audience is a community. A low ADI means the audience is a number.

The gradient tells the agent where to focus: if PCR is low, the agent builds owned surfaces. If ADI is low, the agent builds direct relationships. If CD is low, the agent closes transactions and produces receipts.
